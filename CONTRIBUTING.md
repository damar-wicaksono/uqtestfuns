# Contribution Guidelines

First, thank you very much for taking the time to contribute
to the UQTestFuns project!

This document provides guidelines for contributing to the UQTestFuns project,
its codebase and documentation. 
These guidelines are mostly, well, guidelines;
they are not rules written in stone.
In case of doubt, use your best judgment.
Don't hesitate to propose changes to this document via an issue or 
in a pull request.

This project and everyone participating in it is governed by our [Code of Conduct](./CODE-OF-CONDUCT.md).
By participating, you are expected to uphold this code.

The [Contributor's Guide](https://uqtestfuns.readthedocs.io/en/latest/development/overview.html)
covers everything you need, including:

- [Requesting a new test function](https://uqtestfuns.readthedocs.io/en/latest/development/overview.html#requesting-a-new-test-function)
- [Setting up a development environment](https://uqtestfuns.readthedocs.io/en/latest/development/setting-up-dev-env.html)
- [Adding a new test function](https://uqtestfuns.readthedocs.io/en/latest/development/adding-test-function-implementation.html)
- [Adding a new test function's documentation](https://uqtestfuns.readthedocs.io/en/latest/development/adding-test-function-docs.html)
- [Adding a new univariate distribution](https://uqtestfuns.readthedocs.io/en/latest/development/adding-marginal-distribution.html)
- [Making a pull request](https://uqtestfuns.readthedocs.io/en/latest/development/making-a-pull-request.html)
- [Reporting a bug](https://uqtestfuns.readthedocs.io/en/latest/development/overview.html#reporting-and-fixing-a-bug)
