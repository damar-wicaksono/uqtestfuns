Listing Available Probabilistic Input Specifications
====================================================

The signatures below reflect ``tabulate``'s effect on the return value:
with ``tabulate=True`` (default), the function prints a table and returns
``None``; with ``tabulate=False``, it returns a list of input-specification
IDs instead.
